# VyoMax Maxi Carbs — Session 1

This is the first production-ready foundation of the Maxi Carbs website.

## Included
- Cinematic loading screen
- Mobile-first premium hero
- Stylised Maxi Carbs bottle visual
- Scroll-driven product motion
- Particle ambience and cursor glow
- Responsive navigation
- Product story and Dietly call-to-action
- Google Maps and Instagram links

## Deploy on GitHub Pages
1. Create a new public repository.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait around one minute, then open the published URL.

No build process or npm installation is required.
