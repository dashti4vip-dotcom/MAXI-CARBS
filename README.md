# VyoMax Maxi Carbs — Session 03

This build adds the complete five-flavour system:

- Apple
- Grape
- Blue Exotic
- Strawberry
- Watermelon
- Swipe left/right on mobile
- Previous/next controls on desktop
- Dynamic background, lighting and accent colours
- A cinematic pinned flavour gallery
- All 25 real product angles
- The 360° inspection section updates to the selected flavour

## Upload to GitHub Pages

1. Delete or replace the old files in the existing `MAXI-CARBS` repository.
2. Upload everything **inside** this folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - the complete `assets` folder
3. Keep `index.html` at the repository root.
4. Wait 1–3 minutes, then refresh the existing GitHub Pages link.

Do not upload the outer `maxi-carbs-session-3` folder as an extra level.
