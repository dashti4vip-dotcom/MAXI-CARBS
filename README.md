# Maxi Carbs — Session 6

This session upgrades the existing site into an Apple-only **3D prototype**.

## What changed
- Real-time 3D bottle scene using **Three.js / WebGL**.
- Stronger studio lighting and reflections.
- Scroll-linked motion for the bottle and camera.
- Same project structure, still easy to upload to GitHub Pages.

## Upload instructions
1. Delete the old session files from your GitHub repository.
2. Upload **everything inside this folder**.
3. Keep this structure at the repository root:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - `assets/`
4. Wait 1–2 minutes and refresh the GitHub Pages link.

## Notes
- This is a prototype for **Apple flavour only**.
- The goal is to test whether 3D gets closer to the reference quality before rebuilding the other flavours.
